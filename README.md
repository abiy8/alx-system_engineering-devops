# Shell and Linux Fundamentals

ALX coursework in shell navigation, file permissions, redirection, variables, and expansions.

**Stack:** Shell · Bash · Linux

## Contents

`0x00-shell_basics/`, `0x01-shell_permissions/`, `0x02-shell_redirections/`, and `0x03-shell_variables_expansions/` contain individual exercises.

## Usage and scope

Inspect scripts before running them. Some intentionally move or remove files or change permissions, so use a disposable exercise directory rather than a production system.
